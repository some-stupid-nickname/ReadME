# Книжный RAG-ассистент

Система рекомендации книг на основе RAG (Retrieval-Augmented Generation) с Mistral LLM.

## Архитектура

Система состоит из трёх основных этапов обработки запроса:

### 1. Query Translation (Перевод запроса)

Пользователь вводит запрос на русском языке. Mistral LLM переводит его в английские ключевые слова для поиска (база книг на английском).

### 2. Retrieval (Поиск)

Кодирование ключевых слов в вектор через SentenceTransformer (модель all-MiniLM-L6-v2, размерность 384). Затем вычисляется косинусное сходство между вектором запроса и векторами всех книг в базе. Возвращаются top-k наиболее похожих книг (от 3 до 5).

**Алгоритм:**
1. Нормализация вектора запроса
2. Вычисление скалярного произведения с нормализованными векторами базы
3. Сортировка по убыванию сходства
4. Выбор top-k результатов

### 3. Generation (Генерация)

Модель генерирует персонализированный ответ с рекомендациями на русском языке, учитывая историю диалога.

## Реализация

### BookDatabase

Класс для работы с базой данных книг.

**Загрузка данных:**
1. Подключение к SQLite базе `books.sqlite`
2. Извлечение сериализованных объектов PointStruct через pickle
3. Парсинг метаданных: название, автор, категория, описание, издательство, цена, год
4. Формирование NumPy массива векторов (103063 × 384)


### VectorSearchEngine

Класс для семантического поиска.

**Принцип работы:**
1. Кодирование текстового запроса в вектор
2. Вычисление косинусного сходства 
3. Опциональная фильтрация по категории
4. Возврат отсортированного списка 

### BookRAGAssistant

RAG-ассистент с поддержкой диалога.

Поддерживает историю - запоминает 3 последних сообщения для понимания контекста, запоминает использованные фразы для исключения одинаковых описаний книг

**Обработка запроса:**
1. Сохранение запроса в историю
2. Перевод запроса в английские ключевые слова через LLM
3. Поиск релевантных книг
4. Формирование контекста с найденными книгами
5. Отправка запроса в Mistral с system prompt и историей
6. Сохранение ответа в историю диалога

## База данных

- **Количество книг:** 103,063
- **Размерность векторов:** 384
- **Размер файла:** 514 MB
- **Формат:** SQLite с сериализованными PointStruct объектами


# Для тестирования необходимо:

## 1. Установить зависимости

```bash
pip install -r requirements.txt
```

## 2. Настроить API ключ Mistral

Создайте файл `.env` в папке проекта:
```
MISTRAL_API_KEY=ваш_ключ_от_mistral
```

Или экспортируйте переменную:
```bash
export MISTRAL_API_KEY=ваш_ключ_от_mistral
```

## Запуск

```bash
python backend_rag.py
```

## Команды интерактивного режима (дублируются в терминале при запуске)

- `/clear` — очистить историю диалога
- `/quit` — выход
