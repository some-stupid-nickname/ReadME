# Примеры использования Telegram бота

## Начало работы

### 1. Запуск бота

```bash
# Из корня проекта
cd telegram-bot
python bot.py
```

Или через Docker:
```bash
cd docker
docker-compose up telegram-bot
```

### 2. Настройка

Создайте файл `.env` в корне проекта или в `telegram-bot/`:
```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
API_URL=http://localhost:8000
```

Получить токен можно у [@BotFather](https://t.me/BotFather) в Telegram.

## Основные команды

### `/start` - Начать работу

```
Пользователь: /start

Бот: Привет! Я помогу тебе найти интересные книги. 
     Просто напиши, что тебя интересует, например:
     "хочу почитать про космос"
     "детективы с неожиданной развязкой"
     "бизнес-книги про стартапы"
```

### Поиск книг

```
Пользователь: фантастика про драконов

Бот: О, драконы и магия — это же просто волшебство! 🐉✨
     
     Вот что я нашёл для тебя:
     
     1. «Поиски драконов: Хроники Зачарованного леса, Книга вторая» от Патриции Уред
        Эта книга — просто находка для любителей приключений! 
        Представь: король отправляется в опасное путешествие, чтобы спасти свой лес, 
        и встречает принцессу, которая не прочь поспорить с драконами...
        
     [Ещё 4 книги...]
```

### Уточнение запроса

```
Пользователь: а что-то более современное?

Бот: Конечно! Вот более современные варианты:
     
     1. «Драконы: Фантазия, ставшая реальностью» от Charlie Foley
        Современный взгляд на драконов в фантастике...
```

### Очистка истории

```
Пользователь: /clear

Бот: История диалога очищена. Начнём заново!
```

## Навигация

Бот поддерживает кнопки для навигации:

- **"Ещё книги"** - получить дополнительные рекомендации по текущей теме
- **"Другая тема"** - начать новый поиск
- **"Очистить историю"** - сбросить контекст диалога

## Особенности

### Контекст диалога

Бот запоминает последние 3 запроса и учитывает их при генерации ответов:

```
Пользователь: детективы
Бот: [Рекомендует детективы]

Пользователь: а что-то похожее?
Бот: [Рекомендует похожие детективы, не повторяя предыдущие]
```

### Персонализация

Бот адаптирует ответы под стиль общения:
- Использует дружелюбный тон
- Добавляет эмодзи для выразительности
- Объясняет выбор простыми словами
- Предлагает конкретные книги с описаниями

## Обработка ошибок

### Если API недоступен

```
Бот: Извини, сейчас не могу подключиться к серверу. 
     Попробуй позже или проверь, что backend запущен.
```

### Если запрос пустой

```
Пользователь: [отправляет пустое сообщение]

Бот: Напиши, что тебя интересует! Например:
     "хочу почитать про космос"
```

### Если ничего не найдено

```
Бот: О, это интересная тема! К сожалению, в базе не нашлось 
     точных совпадений, но вот что может тебе понравиться:
     [Рекомендует похожие книги]
```

## Интеграция с API

Бот использует FastAPI backend для получения рекомендаций:

```
Telegram Bot → HTTP POST → FastAPI /api/search → RAG System → Response
```

### Формат запроса к API

```json
{
  "query": "фантастика про драконов"
}
```

### Формат ответа от API

```json
{
  "response": "О, драконы и магия...",
  "books": [
    {
      "id": "book_123",
      "title": "The Book of Dragons",
      "author": "By Nesbit, Edith",
      "genres": ["Fiction"],
      "description": "..."
    }
  ]
}
```

## Troubleshooting

### Бот не отвечает

1. Проверьте, что backend запущен:
   ```bash
   curl http://localhost:8000/api/health
   ```

2. Проверьте токен в `.env`:
   ```bash
   cat .env | grep TELEGRAM_BOT_TOKEN
   ```

3. Проверьте логи бота:
   ```bash
   # Если через Docker
   docker logs rag-telegram-bot
   
   # Если локально
   # Логи выводятся в консоль
   ```

### Ошибки подключения к API

Убедитесь, что:
- Backend запущен на порту 8000
- `API_URL` в `.env` указан правильно
- Нет проблем с сетью между контейнерами (если используете Docker)

### Проблемы с базой данных

Убедитесь, что:
- Файл `data/storage.sqlite` существует
- Путь к базе указан правильно в `BOOKS_DB_PATH`
- База содержит книги (проверьте через скрипт `tests/check_book_data_quality.py`)
