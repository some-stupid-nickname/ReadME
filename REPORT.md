# Отчет по проекту: RAG-система рекомендации книг

## Функционал интерфейса

Проект предоставляет три основных интерфейса для взаимодействия с системой рекомендации книг:

### 1. CLI Консольный интерфейс (`frontend/console_interface.py`)

**Основные возможности:**
- Интерактивный режим с поддержкой истории диалога
- Векторный поиск по базе книг (103,063 книги)
- Рекомендации на основе семантического поиска
- Поддержка команд: `/clear` (очистка истории), `/quit` (выход)

**Пример работы:**
```
Пользователь: хочу почитать про космос

Бот: О, космос и звезды — это же просто космос! ✨

Вот что я нашёл для тебя:

📚 "Автостопом по галактике" - Дуглас Адамс
Юмористическая космическая одиссея...

📚 "Марсианин" - Энди Вейр
Реалистичная история выживания астронавта на Марсе...

📚 "Дюна" - Фрэнк Герберт
Эпическая научная фантастика...
```

### 2. Telegram Бот (`telegram-bot/bot.py`)

**Основные возможности:**
- Удобный интерфейс через Telegram
- Поддержка команд: `/start`, `/help`, `/clear`
- Сохранение истории диалога для каждого пользователя
- Адаптивные ответы на русском языке
- Интеграция с backend API

**Пример работы:**
```
Пользователь: фантастика про драконов

Бот: О, драконы и магия — это же просто волшебство! 🐉✨

Вот что я нашёл для тебя:

📚 "Игра престолов" - Джордж Р. Р. Мартин
Эпическая фэнтези с драконами и интригами...

📚 "Колдовской мир" - Роулинг Джоан
Истории о волшебстве и драконах...
```

### 3. REST API (`backend/api/main.py`)

**Основные эндпоинты:**
- `POST /api/search` - анонимный поиск книг
- `POST /api/chats/{chat_id}/messages` - поиск с сохранением истории
- `GET /api/chats` - список чатов пользователя
- `POST /api/messages/{message_id}/feedback` - оценка ответов (лайк/дизлайк)

**Пример запроса:**
```json
POST /api/search
{
  "query": "хочу что-то про космос"
}

Response:
{
  "response": "О, космос и звезды — это просто космос! ✨ Вот что я нашел...",
  "books": [...],
  "message_id": null
}
```

## Инструкция по запуску

### Вариант 1: Запуск через Docker (рекомендуется)

```bash
# 1. Клонируйте репозиторий
git clone <url>
cd ReadME

# 2. Настройте переменные окружения
cd docker
cp .env.example .env
# Отредактируйте .env и укажите:
# - MISTRAL_API_KEY (обязательно)
# - TELEGRAM_BOT_TOKEN (если используете бота)
# - BOOKS_DB_PATH (путь к data/storage.sqlite)

# 3. Запустите все сервисы
docker-compose up -d

# 4. Проверьте работу
# Backend API: http://localhost:8000/docs
# Telegram бот: начните диалог с ботом в Telegram
```

### Вариант 2: Локальный запуск

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Настройте переменные окружения
# Создайте .env в корне проекта:
# MISTRAL_API_KEY=your_key_here
# BOOKS_DB_PATH=data/storage.sqlite

# 3. Запустите backend
cd backend
python -m api.main

# 4. В другом терминале запустите Telegram бот (опционально)
cd telegram-bot
python bot.py

# 5. Или используйте CLI интерфейс
cd frontend
python console_interface.py
```

### Проверка базы данных

Перед запуском убедитесь, что база данных существует:

```bash
# Проверка качества данных
python tests/check_book_data_quality.py --db-path data/storage.sqlite
```

## Технические характеристики

- **База данных:** 103,063 книги в SQLite с векторными эмбеддингами
- **Модель эмбеддингов:** all-MiniLM-L6-v2 (384 измерения)
- **LLM:** Mistral AI API (mistral-small-latest)
- **Метрики качества:** RAGAS (faithfulness, answer_relevancy, context_precision, context_recall)
- **Интерфейсы:** REST API, Telegram бот, CLI консоль
- **Развертывание:** Docker + docker-compose

## Архитектура системы

```
Пользователь
    ↓
[CLI | Telegram Bot | API] → Backend (FastAPI)
    ↓
RAG-система: Query Translation → Retrieval → Generation
    ↓
SQLite база данных (векторы + метаданные книг)
```
